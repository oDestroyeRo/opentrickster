# OpenTrickster

Domain terms for the Trickster bot's operating modes and progression research.

## Language

**Game client**:
The game's visual application through which a player sees and controls a character.
_Avoid_: Bot UI, information dashboard

**Client-assisted mode**:
Bot operation with the game client visible inside the bot application.
_Avoid_: UI mode

**Clientless mode**:
Bot operation that controls a character without running the game client.
_Avoid_: Headless mode

**Information dashboard**:
The bot application's display of game state and automation activity.
_Avoid_: Game client

**Quest leveling route**:
An ordered plan of quests and their associated activities used to gain character levels.
_Avoid_: Automatic questing
