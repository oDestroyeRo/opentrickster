# Domain docs

This repository uses a single-context layout.

## Before exploring

Read root `GLOSSARY.md` and relevant decisions in `docs/adr/`.
If either is absent, proceed silently. Domain-modeling work
creates these files when terminology or decisions are resolved.

## Vocabulary

Use domain terms as defined in `GLOSSARY.md`.
If a needed concept is missing, identify the gap for
domain-modeling work.

## Decisions

Read architecture decisions relevant to the work.
If a proposal contradicts an existing decision, name that
decision and explain why it needs reconsideration.
